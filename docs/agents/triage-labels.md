# Triage Labels

This table gives the GitHub label for each of the five triage roles.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | A maintainer must examine the issue.  |
| `needs-info`               | `needs-info`         | The reporter must give more information. |
| `ready-for-agent`          | `ready-for-agent`    | An agent can do the work without human input.  |
| `ready-for-human`          | `ready-for-human`    | A person must do the work.            |
| `wontfix`                  | `wontfix`            | The project will close the issue without a change.                     |

When a skill names a role, use its label from the table.

If a label changes in GitHub, change its name in the "Label in our tracker" column.
