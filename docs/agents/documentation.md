# Documentation standard

Use ASD-STE100 Issue 9 for new or changed English prose. See the
[writing rules and dictionary](https://www.asd-ste100.org/about_STE.html).

- Use approved words with their approved meanings and parts of speech.
- Use technical terms when necessary. Use the same term for the same concept.
  See the [glossary](../../GLOSSARY.md) for project terms.
- Use the active voice. Name the person or component that does the action.
- Start an instruction with an imperative verb. Give one action in each
  instruction. Use a maximum of 20 words in each instruction sentence.
- Use a maximum of 25 words in each descriptive sentence. Give one topic in
  each paragraph. Use a maximum of six sentences in each paragraph.
- Use lists for sequences and groups. Do not use contractions or semicolons.

Keep published changelog entries as historical records. Preserve commands,
code examples, identifiers, exact interface text, quotations, legal text,
and the template text that GitHub workflows check.

A checker can find some errors. Review word meanings, technical terms, and
procedures against the standard and the software.
